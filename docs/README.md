# Documentation index

These documents are the build artifacts for the game. They record **locked** decisions from project discussion and leave **stubs** wherever nothing was decided.

Do not fill stubs with invented lore, races, types, names, numbers, or flavor.

| Status | Meaning |
| --- | --- |
| Locked | Agreed in discussion. Implement against this. |
| Default | Agreed as the stack/architecture default. Change only by explicit decision. |
| Stub | Placeholder. Empty on purpose until discussed. |
| Open | Question to resolve. No answer yet. |

## How to read this

1. [Decisions log](01-decisions.md) — what is already decided
2. [Open questions](02-open-questions.md) — what is not
3. Product, design, engineering, assets, plan — in that order
